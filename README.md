# 🤝 Foldgarant — Telegram гарант-бот

Гарант-бот (escrow) для безопасных сделок в Telegram с оплатой через
[Crypto Pay API](https://help.crypt.bot/crypto-pay-api) (@CryptoBot),
профилями пользователей и системой репутации.

## Возможности

- **Гарант-сделки**: деньги покупателя замораживаются у бота и выплачиваются
  продавцу только после подтверждения получения товара/услуги.
- **Сделка прямо в чате** (inline, как `@send` у CryptoBot): в любом диалоге
  введите `@имя_бота 25 USDT описание`, выберите роль — собеседнику придёт
  приглашение с кнопкой «Присоединиться».
- **Оплата через CryptoBot**: счета (invoice) и выплаты (transfer) в USDT, TON, BTC.
- **Профиль**: количество завершённых сделок, оборот, дата регистрации.
- **Репутация**: оценки 👍/👎 и текстовые отзывы после каждой сделки,
  просмотр чужого профиля по ID (`/whois`) перед сделкой.
- **Споры**: любая сторона может открыть спор по оплаченной сделке,
  администратор решает — выплатить продавцу или вернуть покупателю.
- **Админка**: список споров, баланс приложения, бан/разбан пользователей.

## Как проходит сделка

1. Участник создаёт сделку (`/newdeal`): роль, валюта, сумма, описание —
   и получает ссылку-приглашение.
2. Второй участник переходит по ссылке и присоединяется.
3. Бот выставляет покупателю счёт в @CryptoBot. После оплаты средства
   находятся в холде на балансе приложения Crypto Pay.
4. Продавец передаёт товар/услугу.
5. Покупатель подтверждает получение — бот переводит продавцу сумму за
   вычетом комиссии сервиса (transfer в @CryptoBot).
6. Обе стороны оценивают друг друга — формируется репутация.

Если что-то пошло не так: продавец может вернуть деньги покупателю в один
клик, либо любая сторона открывает спор для администратора.

## Установка

Есть два способа запустить бота:

- **Cloudflare Workers (бесплатный хостинг, без сервера)** — порт бота на
  TypeScript в каталоге [worker/](worker/): вебхуки вместо polling, база
  Cloudflare D1. Инструкция: [worker/README.md](worker/README.md).
- **Свой сервер/VPS (Python)** — оригинальная версия ниже.

```bash
git clone <repo>
cd foldgarant
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # заполните значения
python main.py
```

### Настройка

1. Создайте бота у [@BotFather](https://t.me/BotFather) → `BOT_TOKEN`.
2. Создайте приложение Crypto Pay: [@CryptoBot](https://t.me/CryptoBot) →
   Crypto Pay → Create App → `CRYPTOPAY_TOKEN`.
   Для тестов используйте [@CryptoTestnetBot](https://t.me/CryptoTestnetBot)
   и `CRYPTOPAY_TESTNET=true`.
3. Впишите свой Telegram ID в `ADMIN_IDS` (узнать: @userinfobot).
4. **Для inline-режима** (создание сделки через `@имя_бота ...` в любом чате)
   настройте бота у @BotFather:
   - `/setinline` → задайте placeholder, например `сумма валюта описание`;
   - `/setinlinefeedback` → **Enabled (100%)** — без этого бот не узнает,
     что сообщение отправлено, и сделка не создастся.

Все параметры описаны в [.env.example](.env.example).

### Важно про выплаты

- Выплаты делаются методом `transfer` Crypto Pay — получатель должен хотя бы
  раз запустить @CryptoBot, иначе перевод не пройдёт.
- Комиссия сервиса (`COMMISSION_PERCENT`) остаётся на балансе приложения.
- При ошибке выплаты бот уведомляет администраторов — средства остаются на
  балансе приложения, и их можно выплатить вручную.

## Структура проекта

```
main.py               — точка входа, запуск бота и фоновых задач
bot/
  config.py           — конфигурация из .env
  cryptopay.py        — клиент Crypto Pay API
  db.py               — SQLite: пользователи, сделки, оценки
  services.py         — выплаты/возвраты/уведомления
  watcher.py          — фоновая проверка оплаты счетов
  middlewares.py      — блокировка забаненных
  keyboards.py        — inline-клавиатуры
  states.py           — FSM-состояния
  utils.py            — форматирование карточек сделок и репутации
  handlers/
    start.py          — /start, deep-link приглашения, помощь
    inline.py         — сделка через @имя_бота прямо в чате
    profile.py        — /profile, /whois
    deals.py          — создание сделки, оплата, холд, споры
    ratings.py        — оценки и отзывы
    admin.py          — /disputes, /balance, /ban, /unban
```
